# RAG 完整链路与架构选型（系列）

这是一套面向工程落地的 RAG 深度指南，共十章。与 [RAG 工作机制详解](../RAG工作机制详解.md) 的分工是：那篇讲"是什么"，这套讲"**怎么搭、怎么选**"。

## 这套文档回答什么

| 问题 | 对应章节 |
| --- | --- |
| 每一环具体怎么做，参数怎么调 | 第三章、第四章、第五章、第六章 |
| 组件和模型怎么选，为什么这么选 | 第七章、第八章 |
| 效果怎么衡量，改完到底有没有变好 | 第九章 |
| 什么阶段做什么事，避免过度设计 | 第二章、第十章 |

## 阅读建议

- **首次通读**：按 01 → 10 顺序读，第二章的全链路总览建立全局视角，后面再逐环深入。
- **只关心选型**：直接跳到 07（模型选型，限国内）与 08（架构选型），两者都附了决策表与许可陷阱。
- **正在调效果**：看 04（召回）、05（重排）、09（评估）。调参前先建评估集，否则无法判断改动是优化还是退化。
- **要上线**：09 的检查清单按链路环节分组，可直接当核对表用。

## 关于证据

每章都区分「来源」「工程推断」「未核实」三类信息。全文引用的论文、官方文档、模型卡均附可点击来源与查看日期；无法取得来源的条目集中在附录的未核实清单里，**不做推测填充**。

需要强调：引用公开来源的结论，不等于在你们自己的语料上验证过。凡是没有在自有数据上验证过的参数，都应视为待调项。
